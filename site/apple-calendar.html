Check Apple Calendar

Choose the appointments that make you busy today. Alongside compares the selected times with your plan. First, finish your profile and save your plan on the regular Alongside website in your default browser on this device. The helper opens that plan when you run it.

On a Mac

Download the Calendar helper
  1. Open the downloaded file in Script Editor, which comes with your Mac. Click the triangular Run button.
  2. Choose Choose calendars. Allow Script Editor to access Calendar if your Mac asks. Select your appointment calendar.
  3. Pick the appointments that make you busy. Leave free time and Alongside reminders unchecked. Choose Open Alongside to review any overlaps.

The helper shows timed entries Calendar makes available for today, up to 100. Check the list before continuing. For a repeating appointment missing from the list, use the Shortcuts steps below on Mac or iPhone.

On an iPhone or iPad

Use Apple’s Shortcuts app to create this check once. Then tap the shortcut whenever you want to check today’s plan.

Build the Calendar shortcut
  1. Tap + in Shortcuts. Name the shortcut Alongside Calendar. Add Find Calendar Events. Set Start Date is today and Is All Day is false. Set the limit to 100.
  2. Add Choose from List using the calendar events. Turn on Select Multiple. Leave Select All Initially off.
  3. Add Repeat with Each using Selected Items. Put the next three steps inside that repeat.
  4. Add Get Details of Calendar Events. Choose Start Date from Repeat Item. Add Format Date, select ISO 8601 and turn on Include ISO 8601 Time.
  5. Add another Get Details of Calendar Events. Select End Date and set its input back to Repeat Item. Format that date with the same settings.
  6. Add Text. In one line insert the first formatted date, type the character |, then insert the second formatted date. Insert the two date variables from the actions above.
  7. After End Repeat, add Combine Text. Choose Repeat Results with New Lines. Add URL Encode for the combined text.
  8. Add URL. Type https://hintofhala21.github.io/alongside/#apple-busy= and insert the encoded text variable immediately after the equals sign. Add Open URLs using that URL.

Tap the shortcut and allow Calendar access when Apple asks. Select busy appointments only, then review the results in Alongside. Shortcuts searches appointments starting today, so check overnight events separately.

What gets shared

Your selection opens in Alongside as start and end times. Appointment names and locations stay in Apple Calendar and the local picker. Run the check again when your appointments change. Anyone with the generated link can see the selected times, so keep that link private.
